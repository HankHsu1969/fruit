# 水果盤 FRUIT MACHINE（九宮格 8 線）

仿早期台灣電子遊藝場的「水果盤」拉霸機台：三輪 × 三列的九宮格，8 條線（3 橫、3 直、2 斜）。
純 HTML + CSS + JavaScript，不需安裝任何套件。懷舊娛樂模擬，金額僅為遊戲顯示，沒有任何實際價值。

## 怎麼開

- 直接用瀏覽器打開 `index.html` 就能玩（音效已內嵌，雙擊開啟也有聲音）。
- 開啟時先顯示載入封面（遊戲載入中，請稍後＋進度條），圖片與音效都載入完成後才淡出、顯示機台。
- 或在上一層 `Game` 資料夾用 Claude 的預覽伺服器 `fruit`（`python -m http.server 8124 --directory fruit`），開 <http://localhost:8124>。

## 金額

1 分 = 10 元，畫面上的押注、贏得金額、餘額全部以「元」顯示。

- 每線押注 10–100 元（押注鍵循環），押 1–8 線，最大注 = 8 線 × 100 元 = 800 元
- 投幣一次 +100 元，第一次開機送 1,000 元

## 經典玩法

| 按鈕 | 鍵盤 | 說明 |
|---|---|---|
| 投幣 | `C` | +100 元 |
| 押注 | `Q` / `↑` | 每線押注 10–100 元循環 |
| 押線 | `W` / `→` | 押 1–8 條線循環（依中橫、上橫、下橫、左直、中直、右直、左斜、右斜的順序開放） |
| 最大注 | `E` | 8 線 × 100 元 |
| 轉/全停 | `空白鍵` / `Enter` | 開始轉；轉動中再按一次三輪一起停 |
| 停1 停2 停3 | `1` `2` `3` | 個別停輪 |
| 得分 | `T` | 把贏得金額收進餘額 |
| 比倍/大、小 | `B`、`S` | 中獎後猜大小：電眼開 1–13，小 = 1–6、大 = 8–13，開 7 莊家通殺；猜中加倍，可以一直比 |
| 自動 | `A` | 連續轉並自動收分，再按一次停止 |
| 音效 | `M` | 開關音效 |

**WILD 百搭**：可以當成任何圖示。WILD＋兩個相同圖示就算三個一樣（例如 WILD＋西瓜＋西瓜 = 西瓜 ×3），
也能湊任意 BAR、湊櫻桃；一條線上有 WILD 時自動算成最划算的組合。WILD 只出現在中間那一輪（輪上有 2 個，約每 4–5 局畫面上會看到一次）。

|---|---|---|---|---|---|
| 倍數 | 100 | 500 | 1000 | 2000 | 3000 |

## 機率

三條輪帶各 30 格，每格有自己的權重（虛擬輪帶）：每輪都有一段連續三個 77，每圈都看得到它轉過去，
但停在那裡的權重很小，所以 77 大獎很罕見。押滿 8 線時（`node tools/sim.js` 依權重精算的結果）：

- **中獎**：約每 2 局 1 次（49%）
- **大獎**（單局贏得 ≥ 總押注 3 倍，會播大獎音效並顯示「大獎」）：約每 6.5 局 1 次（15%）
- **回饋率**：約 97%（不含比倍）；押 1–7 線時也都低於 100%
- 全盤水果約 9,000 局一次；畫面上 5 個 77 約 1 萬局一次、6 個 77 約 10 萬局一次，7–9 個 77 是數百萬局才一次的超級大獎

輪帶與權重在 `core.js` 的 `REELS`、`WEIGHTS`，改完請跑 `node tools/sim.js` 重算。

## 音效

全部取自 HeyGen 音效庫，經裁切、疊層（投幣 = 硬幣聲 + 加分提示；全盤 = 鈴聲 + 硬幣灑落）與響度平衡，放在 `sfx/*.mp3`；
每個音效的 HeyGen 原始名稱與編號見 `sfx/CREDITS.md`。

- 中獎音效分三級（押滿 8 線時的出現頻率）：**小獎**（贏回不到總押注，約每 3.7 局）歡樂慶祝短樂句；**中獎**（總押注 1–3 倍，約每 35 局）慶祝號角；**大獎**（3 倍以上，約每 5 局）拉炮＋銅管樂＋歡呼＋硬幣的慶祝音樂。
- 輪子一到位就響一聲小小的停輪聲（木頭「叩」）；最後一輪到位的同時開獎、放中獎音樂。
- **得分（入金）**：像小瑪莉收分，一開始一分一分慢慢數、越數越快，每數一下都響一次跟投幣一樣的聲音（硬幣落下＋加分提示）；同時只有一聲，最後一下完整播完，大獎也在約 2 秒內收完。
- **試聽**：打開 `audition.html` 可以聽小獎、中獎、停輪的各個候選音效，選好再換進遊戲。
- **比大比小**：小鼓滾奏一路加強、電眼越跳越慢，最後一記重擊時開出數字；猜中是收銀機叮噹＋歡呼，沒中是卡通「啵～嗡」。

`sfx/sounds.js` 是把這些 mp3 以 base64 打包的檔案；換掉任何 mp3 後執行：

```
node tools/build-sfx.js
```

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 機台版面 |
| `style.css` | 外觀（轉輪、押線指示燈、七段顯示器、跑馬燈泡、圓形按鈕） |
| `core.js` | 規則核心：輪帶、8 條線、賠率、算分、大獎門檻、比倍（瀏覽器與精算共用） |
| `game.js` | 轉輪動畫、遊戲流程、金額顯示、操作與存檔（localStorage） |
| `sound.js` | 音效播放（Web Audio，循環音效淡出） |
| `sfx/` | HeyGen 音效 mp3、打包後的 `sounds.js`、來源清單 `CREDITS.md`、試聽候選 `audition/` |
| `audition.html` | 音效試聽頁 |
| `tools/sim.js` | 中獎率、大獎率、回饋率精算 |
| `tools/build-sfx.js` | 重新打包音效 |
| `img/` | 水果、BAR、WILD 圖示、招牌 Logo、遊藝場背景、載入封面 `cover.jpg`（Higgsfield GPT Image 2 產圖） |
